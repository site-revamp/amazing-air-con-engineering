# Amazing Aircon Homepage Redesign

## Website Overview

Amazing Aircon Engineering Pte. Ltd. provides aircon servicing, repairs, installation, and maintenance for homes and businesses across Singapore. The homepage redesign aims to help visitors find the right service, assess the company, and request a quotation.

## Main Improvements

1. **Make services easier to find.** The original homepage gives services and key information too little visual separation. The redesign calls for distinct, easy-to-scan service sections with direct enquiry links.
2. **Give credibility details more visibility.** Customer reviews, islandwide coverage, and company details are easy to miss. The redesign brings those details forward so visitors can assess the business before making an enquiry.
3. **Simplify mobile enquiries.** Contact options need to be easier to reach as visitors browse. The redesign calls for prominent contact actions and a sticky mobile bar with Call and WhatsApp buttons. The WhatsApp destination requires verification before publication.

## Design Improvements

Clear section headings and distinct service groups make the page easier to scan. Consistent enquiry links connect each service to the next step, and the proposed mobile contact bar keeps those actions within reach while scrolling.
